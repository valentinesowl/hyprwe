## Твои собственные настройки

Мониторы, привычные клавиши и пакеты конкретной машины не должны жить в общем репозитории.
Они находятся в `~/.config/hwe/` — **вне клона**, создаются один раз при установке и больше
никогда не переписываются.

| Файл | Что в нём |
|---|---|
| `hypr.lua` | мониторы, ввод, бинды — подключается **последним** и перекрывает настройки hyprwe |
| `packages.lst` | дополнительные пакеты этой машины из репозиториев дистрибутива |
| `packages-aur.lst` | то же самое из AUR (Arch; на Ubuntu пропускается) |
| `waybar.jsonc` | состав бара — примешивается к сгенерированному конфигу при каждой смене темы |
| `hyprsunset.conf` | расписание ночного света — `hwe sunset` включает и выключает его |
| `kanshi.conf` | профили мониторов — раскладка следует за подключением и отключением дока |
| `themes/` | служебные заметки hyprwe о применённой теме и выбранных обоях |

```bash
$EDITOR ~/.config/hwe/hypr.lua    # мониторы сюда, а не в config/hypr/monitors.lua
hyprctl reload                     # SUPER+SHIFT+R
```

Для reduced motion раскомментируй `local reduced_motion = true`, перезагрузи Hyprland
и один раз выполни `hwe theme apply`. Блок отключает оконные анимации, blur и `borderangle`,
а рендерер убирает переходы Waybar. Без флага воркспейсы и индикаторы сохраняют спокойные
переходы 220 ms. Настройка сохраняется при смене темы и обновлениях.

Для ноутбука с доком мониторам лучше в `kanshi.conf`: профиль применяется, когда все его
выходы подключены. Но у выхода один хозяин: не оставляй для него ещё и вызов `hl.monitor`
в `hypr.lua`, иначе kanshi и Hyprland будут спорить после каждого reload.

**Обновление с hyprwe 1.4:** для нетронутого старого `hypr.conf` новый `hypr.lua` создаётся
автоматически. Если старый файл изменён, `hwe update` остановится до deploy, пока ты сам
не создашь `hypr.lua`. Прежний файл сохраняется для справки: hyprwe не исполняет и не удаляет
его. Остальные Hypr*-инструменты по-прежнему используют `.conf`.

Расположение здесь — и есть весь смысл. `config/` раскатан симлинками в репозиторий, так
что правка на месте была бы правкой **трекаемого файла**, а `hwe update` отказывается тянуть
на грязное дерево. В `~/.config/hwe/` настройки не конфликтуют с pull и переживают замену клона.

Своя тема кладётся в `~/.local/share/hwe/themes/<имя>/` и перекрывает одноимённую поставляемую.
См. [Руководство по темам](../themes/README.ru.md).

`hwe doctor` показывает, что ты сделал своим, и никогда не называет это расхождением. Он
сообщает только про **отсутствующий** файл — `hwe update` вернёт его на место. Изменённый
файл никогда не переписывается; нетронутый следует за поставляемыми дефолтами. Чтобы вернуть
заводские, выполни `hwe update --reset-defaults`: твои версии сохранятся как `*.hwe-bak`.

## Конфиг Hyprland

Точка входа — `config/hypr/hyprland.lua`, которая подключает каждый модуль через `require`:

| Файл | За что отвечает |
|---|---|
| `environment.lua` | переменные окружения сессии |
| `monitors.lua` | fallback-правило выходов (**твои** — в `~/.config/hwe/hypr.lua`) |
| `appearance.lua` | general / decoration / blur / кривые / анимации |
| `theme.lua` | **генерируется** — рамка, геометрия, прозрачность и скорость анимаций |
| `input.lua` | клавиатура (us/ru), тачпад, жесты |
| `keybindings.lua` | бинды с описаниями |
| `windowrules.lua` | правила окон и слоёв |
| `session-layout.lua` | Lua layout provider для точного восстановления сессии |
| `autostart.lua` | один обработчик `hyprland.start` для программ сессии |

Самым последним подключается `~/.config/hwe/hypr.lua`, перекрывающий всё вышеперечисленное.
`hypridle.conf` отвечает за idle → lock/DPMS, `hyprlock.conf` генерируется. При каждом входе
`hwe checkconfig --notify` показывает ошибки синтаксиса, если Hyprland поменял грамматику.

## Основные бинды

`SUPER+T` терминал · `SUPER+N` файлы · `SUPER+B` браузер · `SUPER+R` лаунчер ·
`SUPER+Q` закрыть · `SUPER+V` плавающее · `SUPER+F` фуллскрин · `SUPER+←↑↓→` фокус ·
`SUPER+SHIFT+←↑↓→` двигать окно · `SUPER+1..0` воркспейсы · `SUPER+X` scratchpad ·
`SUPER+S`, затем `1..9` сохранить сессию · `SUPER+S`, затем `SHIFT+1..9` восстановить ·
`SUPER+L` / `SUPER+Escape` лок · `SUPER+Space` раскладка us↔ru ·
`SUPER+SHIFT+T` тема · `SUPER+SHIFT+W` обои · `SUPER+SHIFT+E` меню питания ·
`SUPER+/` шпаргалка биндов · `SUPER+C` буфер обмена · `SUPER+SHIFT+C` цветопипетка ·
`SUPER+ALT+R` / `SUPER+ALT+S` запись экрана (весь / область) ·
`Print` скриншот экрана → буфер · `SHIFT+Print` область → буфер ·
`SUPER+Print` область → `~/Pictures` ·
`SUPER+SHIFT+Print` / `SUPER+P` область с аннотацией → `~/Pictures`.
